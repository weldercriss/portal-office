# AI

Documentação compartilhada entre os agentes de IA do projeto.

- `../AGENTS.md` — regras gerais para qualquer IA
- `../claude.md` — regras específicas do Claude Code, aponta para este diretório
- `CONTEXT.md` — contexto e arquitetura atual do sistema
- `TASKS.md` — tarefas e pendências
- `SESSIONS/` — histórico das sessões, um arquivo por dia (`dd-mm-aaaa.md`)
- `SKILLS/` — convenções e conhecimentos especializados por área

```

AGENTS.md           → Regras gerais para qualquer IA
```
